# 패치노트 — 검과 검 동작 19종

날짜: 2026-09-27 · 브랜치: `feature/sword-animations`

> 그림은 앱 화면 캡처가 아니라 같은 Core 코드로 렌더링한 결과입니다. 새 버튼(검 추가·검 삭제·무기 잡는 자세 맞추기)은 빌드와 테스트, 명령줄 내보내기로 확인했고, 앱 화면에서 직접 누르며 확인하지는 않았습니다.

## 1. 검 추가

파츠 창에 **검 추가 [한손검] [양손검] [도] [단검]**과 **검 삭제**를 넣었습니다.

- 검은 손 R의 자식인 추가 파츠입니다. 가만히 있으면 칼끝이 아래를 향합니다.
- 그림은 옆에서 본 칼 한 장입니다(칼날 3단계 강철색, 풀러, 코등이, 감은 손잡이, 폼멜). 도는 검은 쓰바와 흰 끈 손잡이입니다.
- 길이는 키에 비례합니다(한손검 32%, 양손검 44%, 도 38%, 단검 13%). 칼끝과 손잡이 끝이 장착점으로 들어 있습니다.
- 검을 추가하면 휘두른 칼이 들어가도록 캔버스 좌우와 위를 넓힙니다. 그다음 프로젝트의 **모든 동작**을 검사해, 아직 끝에 닿는 쪽을 더 넓힙니다. 예를 들어 기본 점프에서 팔을 들면 칼도 위로 향합니다. 총도 같은 방식으로 바꿨습니다. 모두 되돌리기 한 번입니다.
- 동작을 가져온 뒤에도 무기가 캔버스 밖으로 나가면 그 자리를 넓힙니다.

## 2. 검 동작 19종 (파일 → 기본 동작 가져오기)

| 분류 | 동작 |
| --- | --- |
| 검 (한손검·단검) | 대기, 걷기, 달리기, 내려베기, 올려베기, 가로베기, 찌르기, 3연격, 막기, 점프 베기, 돌진 베기, 검 뽑기, 승리 |
| 양손검 (양손검·도) | 대기(중단), 걷기, 달리기, 내려베기, 가로베기, 찌르기 |

- 칼이 향하는 방향을 키마다 적고(옆모습: 0° 아래, 90° 앞, 180° 위), 칼 파츠 회전은 손까지의 회전을 빼서 계산합니다.
- 크게 휘두르는 동작은 180°보다 작은 간격으로 키를 넣어, 칼이 의도한 쪽으로 돕니다.
- 내려베기 준비 자세는 칼을 머리 위로 곧게 드는 대신 어깨 너머 머리 뒤로 넘깁니다. 곧게 들면 캔버스 위로 나가기 때문입니다.
- 정면에서는 가로베기가 좌→우로 휘고, 찌르기는 칼끝이 아래(카메라 쪽)를 향합니다.

한손검: 대기 · 내려베기 준비 · 내려벤 뒤 · 가로베기 · 막기 (정면·옆)

![한손검](images/swords-01-one-handed.png)

도: 중단 · 머리 뒤로 들기 · 내려찍기 · 가로베기 (정면·옆)

![도](images/swords-02-two-handed.png)

## 3. 양손 잡기와 무기 잡는 자세 맞추기

- 양손검과 도는 오른손이 코등이 쪽, 왼손이 손잡이 끝을 잡습니다. 왼손은 역운동학으로 붙입니다.
- 왼손이 닿지 않는 자세라면 칼 방향은 그대로 둔 채 오른손을 왼쪽 어깨 쪽으로 당기고, 오른팔도 다시 맞춥니다.
- 파츠 창의 버튼 이름을 **무기 잡는 자세 맞추기**로 바꿨습니다. 총과 검을 함께 맞추고, 되돌리기가 됩니다.
- 한손검은 왼팔을 동작에 적힌 그대로 둡니다.

## 4. 코드

- `HeldItem`: 오른손에 드는 파츠 공통(옆모습 그림을 아래로 돌리기, 뒤에서 반전, 그리는 순서, 장착점, 손바닥 위치)
- `ArmIk`: 두 마디 팔 IK(팔꿈치 아래)
- `WeaponHold`: 동작 키를 총·검에 맞춤
- `CanvasFit`: 캔버스 끝에 닿는 쪽만 넓힘
- 총 코드(`GunPart`, `GunHold`)도 이것들을 쓰도록 정리했습니다.

## 5. 확인

- 테스트 271개 모두 통과합니다. 검 테스트 6개를 추가했습니다(추가·되돌리기·여백, 칼끝 아래, 찌르기 수평, 양손검·도의 왼손 위치 2.5px 이내, 한손검은 왼팔 그대로).
- 4~8등신 생성 마네킹과 손으로 그린 4등신 템플릿에서, 검 네 종류와 총 두 종류로 기본 동작과 무기 동작을 모두 돌렸습니다. 캔버스 끝에 닿는 프레임은 없습니다.
- 7등신 샘플에 한손검(동작 13개)과 도(동작 6개)를 넣어 앱의 명령줄 일괄 내보내기로 내보냈습니다. 경고 없이 GIF 31개가 나왔습니다.
