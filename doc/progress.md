## 2. 5단계 상세 진행

### 완료 (코드 + 테스트)

| 영역 | 내용 |
| --- | --- |
| `.dotchar` 파일 | zip 안에 `project.json`(포맷 버전 1, 팔레트, 외곽선 설정), `skeleton.json`, `animations.json`, `parts/<방향>/<파츠>.png` 48장. 새 버전 포맷은 열기 거부 |
| 이미지 코덱 분리 | Core는 `IImageCodec` 인터페이스만 사용, App이 Avalonia로 PNG 인코딩·디코딩 (`AvaloniaImageCodec`). 템플릿 로딩도 같은 코덱 사용 |
| 스프라이트 시트 | 동작마다 4행(정면·좌·우·후), 열 = 프레임, 칸 96×128. 발 위치 원점 계산. 범용 메타데이터 JSON(칸 크기, 원점, 프레임 좌표·지속시간) |
| GIF | GIF89a 인코더 직접 구현(LZW, 클리어 코드, 투명 색, 무한 반복). 한 동작의 4방향을 가로로 나란히, 배율 지정 |
| 저장 방식 | 임시 파일에 먼저 쓰고 교체 — 저장 실패 시 기존 파일 보존 |
| 설정 | `%AppData%/PixelAniMaker/settings.json`: 최근 파일 8개, 메타데이터 저장 여부, GIF 배율 |
| 메뉴·단축키 | 새로 만들기(Ctrl+N), 열기(Ctrl+O), 최근 파일, 저장(Ctrl+S), 다른 이름으로 저장(Ctrl+Shift+S), 내보내기(현재 동작 시트 Ctrl+E, 전체 통합 시트, 현재 동작 GIF), 메타데이터 체크 |
| 저장 안 한 변경 | 제목 `*` 표시에 동작 설정 변경(이름·프레임 수·fps·반복, 동작 추가·삭제)까지 포함. 새로 만들기·열기·창 닫기 전에 저장/저장 안 함/취소 확인 |
| 테스트 | 63개 통과 (프로젝트 저장→불러오기 왕복, 포맷 버전, 시트 배치·반전·메타데이터, LZW 왕복(클리어 코드 포함), GIF 헤더·팔레트 제한, GIF 크기 추가) |
| 발견·수정한 버그 | `AnimationClip.Keys()` 형변환 오류 — 4단계부터 있던 문제로, 타임라인 "복제" 버튼을 누르면 앱이 멈췄을 것. 테스트로 발견해 수정 |

### 앱에서 확인한 것

- 가슴 파츠에 스카프를 그린 뒤 Ctrl+N → "저장하지 않은 변경" 확인 창 표시 ([스크린샷](patchnotes/images/stage5-02-unsaved-dialog.png))
- "저장" 선택 → 저장 대화상자 → `scarf.dotchar` 생성 (19.5 KB, 항목 51개: JSON 3 + PNG 48, 팔레트·외곽선 포함) → 새 문서로 전환

### 남은 일

- [ ] 창 닫기 시 확인 창 동작 확인

## 4. 알려진 제한

- 프레임 수를 줄이면 범위 밖 키는 지워지지 않고 재생에서만 빠짐
- 기본 동작 6종은 마네킹 기준 초안 — 캐릭터에 맞게 손볼 필요
- 도구 목록에서 이미 선택된 도구를 다시 클릭하면 포즈 모드가 유지됨 (단축키로는 해제됨)
- GIF는 팔레트 256색까지 (넘으면 오류 안내)

## 5. 작업 규칙

- 기능마다 `feature/...` 브랜치 → 완성되면 `main`에 병합
- 작업 단위마다 스크린샷 + 패치노트(`doc/patchnotes/`) 작성 후 커밋·push
- 코드는 SOLID·KISS·DRY 준수
- 스크린샷: `scripts/capture-window.ps1`, UI 조작: `scripts/ui-input.ps1`
