## 2. 5단계 결과

- `.dotchar` 저장·열기·최근 파일, 저장 확인, 시트 PNG + 메타데이터 JSON, GIF, 명령줄 열기·일괄 내보내기
- 검증: 저장 → 명령줄로 다시 열기(화면 확인) → 일괄 내보내기 결과를 Python으로 검사 (자세한 내용은 패치노트)
- 확인 중 발견해 고친 버그: 저장한 파일이 다시 열리지 않던 문제(zip 스트림을 Skia가 읽지 못함), `AnimationClip.Keys()` 형변환 오류(타임라인 "복제"에서 멈춤)
- 앱에서 직접 확인하지 못한 것: 창 닫기 확인 창 (새로 만들기와 같은 로직으로 동작 확인됨)

## 4. 알려진 제한

- 프레임 수를 줄이면 범위 밖 키는 지워지지 않고 재생에서만 빠짐
- 기본 동작 6종은 마네킹 기준 초안 — 캐릭터에 맞게 손볼 필요
- 도구 목록에서 이미 선택된 도구를 다시 클릭하면 포즈 모드가 유지됨 (단축키로는 해제됨)
- GIF는 팔레트 256색까지 (넘으면 오류 안내)

## 5. 작업 규칙

- 기능마다 `feature/...` 브랜치 → 완성되면 `main`에 병합
- 작업 단위마다 스크린샷 + 패치노트(`doc/patchnotes/`) 작성 후 커밋·push
- 코드는 SOLID·KISS·DRY 준수
- 스크린샷: `scripts/capture-window.ps1`, UI 조작: `scripts/ui-input.ps1`
