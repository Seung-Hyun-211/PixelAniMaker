# 계획: 해상도 2배

작성: 2026-09-26 · 상태: **구현됨** ([패치노트](patchnotes/2026-09-26-resolution-scale.md)) · 관련: [캔버스 크기](patchnotes/2026-09-25-canvas-size.md)

## 1. 목적

작게 그린 캐릭터를 픽셀 수 2배(가로·세로 각각)로 키워, 더 세밀하게 다시 그리거나 큰 해상도로 이어 작업한다. 보기 배율(확대/축소)과 달리 **그림 자체**가 커진다.

## 2. 동작

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 편집 → **해상도 2배…** : 방식 고르기 → 한 번에 적용, **되돌리기 한 번** |
| 방식 | **그대로 키우기**(픽셀 하나 → 2×2, 모양이 정확히 같음) · **부드럽게 키우기**(Scale2x: 대각선 계단을 메워 매끈하게, 새 색은 생기지 않음) |
| 크기 제한 | 캔버스 크기 제한(최대 1024)을 넘으면 거부 |

## 3. 함께 커지는 것

| 대상 | 처리 |
| --- | --- |
| 캔버스 | 가로·세로 ×2 |
| 파츠 그림 | 모든 방향(따로 그린 우측면·반측면 포함), 모든 레이어, 각도 이미지 |
| 관절·위치 | 그림 위치, 관절, 각도 이미지 관절, 장착점 ×2 |
| 동작 | 모든 키의 몸 이동 ×2 (회전·그리는 순서는 그대로), 지금 포즈의 몸 이동 ×2 |
| 프레임 손보기 | 손본 픽셀 하나 → 2×2 (두 방식 모두) |
| 설정 | 자동 음영 폭 ×2 (최대 3), 변형형 흔들림 최대 이동 ×2 (최대 6) |
| 참고 이미지 | 위치·배율 ×2 (그림과 계속 겹침) |
| 그대로 | 팔레트, 외곽선 두께(1px), 회전 범위, 그리는 순서, 흔들림의 각도 설정 |

## 4. 되돌리기

그림 크기가 바뀌므로 레이어를 새 그림으로 **바꿔 끼우고**, 되돌리면 원래 레이어 객체를 다시 넣는다. 그래서 2배 이전에 한 그리기도 되돌리기로 그대로 되돌릴 수 있다 (기록 순서대로).

## 5. 테스트 계획

- 그대로 키우기: 모든 레이어 크기 ×2, 픽셀 (x, y) = 원래 (x/2, y/2), 위치·관절 ×2, 합성 결과(외곽선 끔)가 원래 합성을 2×2로 키운 것과 같음.
- 부드럽게 키우기: 대각선이 Scale2x 결과와 같음.
- 동작 키·포즈 몸 이동 ×2, 손본 픽셀 2×2, 각도 이미지·장착점, 음영 폭.
- 되돌리기/다시 하기: 전부 원래대로(같은 그림 객체), 그 전의 그리기도 되돌려짐.
- 크기 제한 거부, 저장·불러오기.
