# 계획: 그리는 순서 (겹치는 파츠의 앞뒤)

작성: 2026-09-25 · 상태: **구현됨** ([패치노트](patchnotes/2026-09-25-draw-order.md)) · 관련: [임의 파츠 추가](plan-custom-parts.md)

## 1. 목적

겹치는 파츠 중 어느 쪽이 앞에 그려질지를 사용자가 정한다.

- **① 방향별 순서**: 방향마다 기본 앞뒤 순서를 바꾼다 (예: 측면에서 망토를 팔 뒤로).
- **② 키별 순서**: 동작 중 특정 키부터 한 파츠를 다른 파츠 앞이나 뒤로 옮긴다 (예: 공격에서 팔이 머리 뒤로 넘어감, 걷기에서 팔이 몸 앞뒤로 교차).

지금은 파츠마다 방향별 순서 값(`skeleton.json`의 `order`, 작을수록 뒤)이 있지만 템플릿 값 그대로이고, 앱에서 바꿀 방법이 없다.

## 2. ① 방향별 순서

| 항목 | 내용 |
| --- | --- |
| 조작 | 파츠 창 "그리는 순서 (이 방향)": **맨 뒤 · 뒤로 · 앞으로 · 맨 앞**. 바로 뒤·바로 앞 파츠 이름과, 이 방향의 전체 순서 목록(앞이 위) |
| 단위 | 파츠 하나와 그 **세부 파츠**(눈·가슴 볼륨)를 한 덩어리로 옮긴다. 세부 파츠는 부모를 따라가므로 직접 옮기지 않는다 |
| 반전 방향 | 우측면·오른쪽 반측면에서 바꾸면 원래 방향(좌측면·왼쪽 반측면)의 순서가 바뀐다 (그림처럼 반전으로 공유). 따로 그린 우측면 그림도 같은 순서를 받는다 |
| 저장 | 바꾼 방향의 모든 파츠 순서를 0, 1, 2 … 로 다시 매겨 기존 `order`에 저장. 형식 변화 없음 |
| 되돌리기 | 한 번 |

## 3. ② 키별 순서

| 항목 | 내용 |
| --- | --- |
| 조작 | 파츠 창 "이 포즈에서만": **기준 파츠**를 고르고 **그 앞 · 그 뒤 · 해제**. 포즈의 일부라서 회전처럼 **K로 키에 저장**한다 (저장 안 하면 "포즈가 키와 다름") |
| 적용 구간 | 순서는 섞을 수 없으므로 계단식: 그 키부터 다음 키 전까지. 다음 키에도 유지하려면 그 키에도 넣는다 |
| 계산 | 방향별 순서에서 그 파츠(덩어리)를 빼서 기준 파츠(덩어리)의 바로 앞/뒤에 넣는다. 여러 개면 파츠 이름 순으로 차례로 |
| 저장 | 키의 포즈에 선택 항목 `"order": { "upper_arm_r": { "anchor": "head", "front": false } }`. 없으면 파일이 이전과 같다 |
| 편집 캔버스 | 지금 포즈의 순서로 보인다 |

## 4. 테스트 계획

- ①: 앞으로/뒤로가 이웃 덩어리와 자리를 바꾼다, 맨 앞/맨 뒤, 끝에서는 더 못 감. 세부 파츠는 부모와 함께. 반전 방향 편집은 원래 방향에 반영. 되돌리기. 저장·불러오기. 합성 결과에서 겹치는 픽셀의 주인이 바뀐다.
- ②: 포즈에 순서를 넣으면 합성에서 앞뒤가 바뀐다. 키 사이 프레임은 앞 키의 순서. 키 저장·불러오기 (JSON). 순서 없는 동작은 파일이 같다 (기준 파일).
